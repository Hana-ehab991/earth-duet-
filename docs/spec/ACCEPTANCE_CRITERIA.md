# Time Travel MVP acceptance criteria

- [ ] React/TypeScript app and backend start with documented commands
- [ ] CesiumJS globe renders and flies to Cairo
- [ ] Historical NASA POWER temperatures are actually retrieved or imported, validated, and attributed
- [ ] NASA GIBS imagery loads for verified available dates; unavailable dates handled
- [ ] Timeline changes selected record, numerical readout, chart, color, and sound consistently
- [ ] Sound only starts after user activation; mute, volume, and safe transitions work
- [ ] NEX-GDDP-CMIP6 future scenario values are genuinely extracted, with model and window documented
- [ ] SSP2-4.5 / SSP5-8.5 selector changes real projection data, not hardcoded values
- [ ] Future map is clearly labeled as projected climate overlay, not future satellite imagery
- [ ] Historical and projected data products are not misleadingly combined
- [ ] Missing data, API failure, and loading states are visible
- [ ] Keyboard, screen-reader labels, accessible color legend, reduced motion and text alternative work
- [ ] Shared globe/data/audio/color services can be reused by later features
- [ ] Tests and build checks pass, or unexecuted checks are transparently reported
- [ ] README, .env.example, methodology, and IMPLEMENTATION_STATUS.md are supplied
